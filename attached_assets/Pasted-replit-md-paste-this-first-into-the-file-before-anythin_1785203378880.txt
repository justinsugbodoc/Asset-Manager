# SugboDoc Patient Portal — Project Context

## Product
SugboDoc is a cloud-native Healthcare Operating System connecting providers,
diagnostics, insurers, employers, and patients in the Philippines.
This app is the Patient Portal for patients to access their health records,
appointments, bills, prescriptions, lab results, and messages with doctors.

## Brand
- Primary color: #4A4FC4 (indigo-blue)
- Secondary: #3A3FA0 (dark indigo)
- Accent: #E8E9FB (light indigo tint)
- Text: #1A1A2E (near-black)
- Success: #1D9E75, Warning: #F59E0B, Danger: #EF4444
- Font: Inter
- Logo: SugboDoc (use text wordmark styled in #4A4FC4 if no image available)

## Tech Stack
- React + Tailwind CSS
- React Router v6 for navigation
- Recharts for charts
- lucide-react for icons
- Mock data only (no backend)

## Responsive Breakpoints
- Mobile < 768px: single column, bottom tab bar navigation
- Tablet 768–1023px: 2-column grid, collapsible sidebar
- Desktop 1024px+: fixed left sidebar 240px, 3-column content grid
- All tap targets minimum 44px height
- No hardcoded pixel widths on content areas — use % or Tailwind fluid classes

## Philippine Context
- Currency: Philippine Peso (₱)
- Clinic names: Cebu Doctors' University Hospital, Perpetual Succour Hospital,
  Chong Hua Hospital, Vicente Sotto Memorial Medical Center
- Sample doctor names: Dr. Maria Santos, Dr. Jose Reyes, Dr. Ana Villanueva
- Specialties: Internal Medicine, Cardiology, Pediatrics, OB-GYN, Dermatology
- Sample patient: Juan dela Cruz, 34M, Blood Type O+
